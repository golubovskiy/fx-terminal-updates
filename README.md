# FX Terminal — установка и обновления

Здесь публикуются установщик и обновления **FX Terminal** — десктоп-терминала для валютного рынка и валютных фьючерсов Московской биржи на **Finam Trade API**. Исходного кода терминала в этом репозитории нет.

> **Статус:** сборка для установки готовится. Первые выпуски появятся в разделе **Releases** этого репозитория.

## Возможности

- **Графики** — свечи и объём, VWAP и SMA, рисование и алерты линий, наложение инструментов, вид графика сохраняется между запусками.
- **Стакан** в стиле CScalp — кластеры, тики, свои заявки, позиция.
- **«Тики Bid/Ask»** — агрессивные покупки и продажи по секундам, лупа для средних объёмов.
- **«Алгоритмы»** — роботы, айсберги, спредовые роботы, наращивание объёма, следы маркет-мейкера на графике и в стакане; уведомления о резком движении цены, крупных сделках и росте оборота.
- **Аналитика** — Order Flow, открытый интерес, опционы (премии, OI, GEX, уровни), CNY Forward.
- **Рабочие пространства** с докингом окон, заметки, журнал уведомлений, учебная торговля (PAPER).

## Что нужно

- Windows 11, 64-бит.
- Брокерский счёт в Финаме и токен **Finam Trade API** (выдаётся в личном кабинете Финама). Токен вводится в «Настройках» терминала и хранится только на вашем компьютере.

## Установка

1. Откройте **Releases** и скачайте установщик последней версии.
2. Запустите его. Права администратора не нужны: терминал ставится в папку пользователя.
3. Запустите FX Terminal и введите токен Finam в «Настройках».

## Обновления

- **Автоматически.** Терминал проверяет этот репозиторий и предлагает установить новую версию.
- **Вручную.** Скачайте пакет обновления из **Releases** и установите через меню «О проекте» → «Установить обновление…».
- Пакеты подписаны: без верной подписи терминал пакет не установит. Если новая версия не запустится, терминал вернёт прежнюю.
- Обновление заменяет только файлы программы — ваши настройки, токен и данные остаются.
